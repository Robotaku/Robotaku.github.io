# 追跡ゲーム (chase-game)

スコットランドヤード風の追跡ゲームです。1台の端末を交代で使って遊びます。人間は2人以上、そこに好きな数のBotを加えられます。

## 概要

- 逃走者1人と追跡者1人以上で遊びます。逃走者は地図上の駅を移動し、その位置は追跡者から隠されます。
- 追跡者は、逃走者が使った移動手段とわずかな位置公開を手がかりに追い詰めます。
- 盤面は駅と路線(タクシー・バス・地下鉄)からなる1つのグラフで、背景に川・公園などの簡易地図を描いています。
- 人間の席とBotの席を自由に組み合わせられます。

## 起動方法

```sh
cd chase-game
npm install
npm run dev      # 開発サーバーを起動
npm test         # テスト(Vitest)を実行
npm run build    # 型チェックのあと dist/ に静的ファイルを出力
```

`npm run build` の出力 `dist/` は静的ファイルだけなので、サーバー用の実行環境は不要です。ただし、`index.html` をファイルとして直接開くとブラウザの制限で動かないことがあるため、任意の静的ホスティングに置くか、簡易サーバーで開いてください。

## 遊び方

1. **トップ画面で席を設定します。** 「＋人間を追加」「＋Botを追加」で席を増やし、「削除」で減らします。各席には名前、人間かBotか、逃走者か追跡者かを設定します。Botには難易度(かんたん・ふつう)もあります。プリセット(人間2、人間2+Bot1、人間2+Bot2、人間1+Bot3)から選ぶこともできます。
2. **席の条件:** 席は2〜8席です。逃走者はちょうど1席、追跡者は1席以上、人間は最低1人必要です。条件を満たさないと「ゲーム開始」は押せません。
3. **ゲーム開始後、手番が人間に替わるたびに中継画面が出ます。** 「端末を○○さんに渡してください」と表示されます。本人がボタンを押すまで盤面は見えません。
4. **移動:** 自分の手番では、移動できる駅が光ります。光っている駅をタップし、移動手段(タクシー・バス・地下鉄)を選ぶと移動します。
5. **推理ヒント(追跡者のみ):** 画面上部のボタンでONにすると、逃走者がいる可能性のある駅がオレンジ色で表示されます。
6. 終了後の結果画面で、逃走者の通った道(点線)とログを確認できます。「同じ設定でもう一度」で再戦できます。

## ルール

### 勝敗

- **追跡者の勝ち:** 追跡者のだれかが、逃走者と同じ駅に止まったとき。また、逃走者が動ける手(駅・チケット)を失ったとき。
- **逃走者の勝ち:** 24ラウンド逃げ切ったとき。また、追跡者が全員動けなくなったとき(チケット切れ、または行き場なし)。

### 手番

- 1ラウンドごとに「逃走者 → 追跡者1 → 追跡者2 …」の順に1回ずつ動きます。
- 動ける手がない追跡者は、自動でパスします。

### 移動手段とチケット

| 手段 | 表示 | 使える場所 | 逃走者 | 追跡者(1人あたり) |
|---|---|---|---|---|
| taxi | タクシー(黄色の線) | 全駅 | 24枚 | 24枚 |
| bus | バス(緑の線) | 駅の下に緑の■がある駅 | 9枚 | 8枚 |
| metro | 地下鉄(赤の線) | 駅の下に赤の■がある駅 | 6枚 | 4枚 |

- 手段を使うとチケットが1枚減ります。残りが0枚の手段は使えません。
- 移動先は、いまの駅から線でつながった隣の駅です。
- 追跡者がいる駅には、逃走者も他の追跡者も入れません。追跡者同士も同じ駅には入れません。

### 位置の公開

- **3・8・13・18・24ラウンド**に逃走者が移動すると、移動後の位置が公開されます(紫のひし形)。
- 公開されるのは位置だけです。それ以外のラウンドは、使った移動手段だけが追跡者に見えます。
- 逃走者は、最初★印の5駅のどれかから始まります。

### 見えるもの

- 追跡者の位置とチケット残りは全員に公開されています。
- 逃走者の位置とチケットは、本人の手番のときだけ本人に見えます。

## Botの考え方

### 逃走者Bot

- 追跡者への最短距離(BFS、手段は問わない)を重く見て、遠い駅を選びます。
- 追跡者が、その駅へ使えるチケットを持って隣接している駅は、大きく減点して避けます(捕まる駅を避けます)。
- 位置公開の直後は、公開された位置から離れる方向を優先します。
- 「かんたん」では、安全な手の中からランダムに選ぶ確率が上がり、評価にもランダム性が加わります。

### 追跡者Bot

- 公開情報だけ(`publicState`)を使います。最後に公開された位置と、その後に使われた移動手段から、逃走者がいる可能性のある駅の集合を計算します。
- 候補の駅に近づく手を選びます。候補の駅に止まる手は加点し、その手段の残りチケットが少ないほど減点します(残り枚数が少ない手段を節約します)。
- 「かんたん」では、ランダムに手を選ぶ確率と評価のランダム性が増えます。

### 手番の間

- Botの手番は約0.8秒の間を置いてから指します。

## 隠し情報の守り方

- 描画には、必ず `publicState()` を通した状態だけを渡します。`publicState()` は逃走者の位置、チケット、軌跡を消します。
- 追跡者Botも `publicState()` の結果だけを参照します。逃走者の本当の位置は見ません。
- デバッグ表示(逃走者の位置を画面とコンソールに出す)は、トップ画面の設定で既定オフです。遊ぶときはオフのままにしてください。

## ファイル構成

```
index.html            エントリHTML
src/main.ts           起動処理
src/style.css         スタイル
src/game/
  types.ts            型定義と移動手段のラベル
  board.ts            盤面データ(駅・路線・開始位置)
  rules.ts            席の検証、合法手、手の適用、勝敗、publicState
  bot.ts              Botの思考(追跡者・逃走者)
  rng.ts              乱数(シード付き)
src/ui/
  app.ts              画面の状態管理と手番の進行
  boardView.ts        盤面のSVG描画
tests/                Vitestのテスト(rules, bot, board, setup, hidden)
```

## 技術

- Vite + TypeScript + Vitest
- 外部ライブラリは使っていません
