# ドット&ボックス

1台のPCやスマホを交代で使って遊ぶ、ドット&ボックスのゲームです。人間2人以上に、好きな人数のBotを加えて対戦できます。

- 1プレイの目安: 標準設定(4×4点)で2〜4分、3×3点なら約1分
- 静的ファイルだけで動き、サーバーは不要です(ビルド後の `play/` をそのまま公開できます)

## 遊び方

- 隣り合う2点の間の線をタップして引きます。
- 四角の4辺目を引くと、その四角を獲得し、続けてもう1本引けます。
- 四角が取れなければ、次の席に手番が移ります。
- 全線が引かれたら終了です。四角が最も多い人が勝ちです。同数の場合や、複数人が同率首位の場合は引き分けです。
- 「ひとつ戻す」は人間の手番でだけ使えます。間に入ったBotの手は、まとめて戻ります。
- Botだけの手番では、画面をタップすると早送りできます。
- 「もう一度遊ぶ」を押すと、設定画面を通らず同じ設定ですぐ再開します。
- 設定は localStorage に保存されます。

## 設定

| 項目 | 内容 |
| --- | --- |
| 席 | 2〜6席。各席で「人間/Bot」「名前(8文字まで)」「色」を決めます。最低1席は人間です。 |
| 色 | 色覚に配慮したパレット(Okabe-Ito系)を使います。色だけに頼らず頭文字も表示します。 |
| 盤面 | 3×3点(四角4個)/ 4×4点(四角9個・標準)/ 5×5点(四角16個) |
| Botの強さ | かんたん / ふつう / つよい(下記)。Botの席があるときだけ表示されます。 |
| Botの速さ | ふつう(0.6秒)/ 速い(0.2秒)/ 即時。Botの席があるときだけ表示されます。 |

## Botの強さ

- **かんたん**: 取れる四角があれば取ります。なければランダムに線を引きます。
- **ふつう**: 取れる四角があれば取ります。なければ、3辺目を作らない線から選びます。それも無ければ、相手に渡す四角が最も少ない線を選びます。
- **つよい**: ふつうと同じ方針で指します。残りの線が17本以下の終盤になると、全探索で最善手を選びます(3×3点は線が12本しかないため、最初の手から全探索します)。2人対戦では、最終的な獲得数の差が最大になる手です。3人以上の場合は近似で、自分の獲得数を最大化し、他の席は自分の獲得数を最小化するものとして探索します。

## 起動方法

Node.js が必要です。

```sh
npm install        # 依存関係のインストール
npm run dev        # 開発サーバー
npm run build      # 型検査のうえ、公開用ビルドを play/ に出力
npm run preview    # ビルド結果の確認
npm test           # テスト(Vitest)
npm run typecheck # 型検査のみ
```

## ファイル構成

```
src/
  game/      ui に依存しない純粋な関数
    types.ts     型定義
    board.ts     盤面の幾何(線・四角の番号)
    rules.ts     手番・獲得・取り消し・勝敗判定
    bot.ts       Botの思考(かんたん/ふつう/つよい)
    settings.ts  設定の既定値・検証・保存
  ui/        画面描画(setup, play, result, svg, dom)
  main.ts    画面遷移とBotの手番の制御
  style.css
tests/       Vitest のテスト
```

ルールとBotは UI から切り離された関数で、Vitest でテストしています。

## 技術

- Vite + TypeScript + Vitest
- 実行時の外部ライブラリはありません
